# LuRa IT Develop — Agent Design Instruction

Build all new LuRa IT Develop web and marketing materials using the attached `LURA_BRAND_GUIDE.md` and `lura-brand-tokens.json` as the visual source of truth.

Core direction: **Dark + Turquoise**.

Mandatory brand colors:
- Primary: #1B242A
- Secondary: #5C7078
- Accent: #2CCFC8
- Background: #F3FAFA
- Surface: #FFFFFF

The supplied LuRa IT Develop logo SVG is the geometry source of truth. Do not redesign or distort it. Recolor only according to the approved variants.

Design intent:
technical, modern, calm, premium, structured, trustworthy, B2B software / IT.
Not gaming, cyberpunk, neon, playful, or overly futuristic.

Critical color rule:
`#2CCFC8` is an accent color. Use it for CTA buttons, icons, active states, diagrams, short highlights and decoration. Do NOT use it for normal body text on white/light backgrounds. For textual links on light backgrounds use `#1B7E7A`.

Primary CTA:
background #2CCFC8, text #1B242A, hover #27B6B0, active #219B96.

Use generous whitespace, white cards, subtle borders (#DDE5E5), restrained shadows, and occasional dark sections (#1B242A) with white/turquoise content.

Typography:
Manrope for headings; Inter for body/UI.

Before implementing any page or asset, map every color to a semantic token. Do not hardcode visually similar random colors and do not introduce extra brand colors without explicit approval.

For the full rules for website, logo variants, print, business cards, email signature, social graphics, favicon, accessibility, spacing, buttons and dark mode, follow `LURA_BRAND_GUIDE.md`.
